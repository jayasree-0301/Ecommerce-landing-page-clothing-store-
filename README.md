# Modern Threads – Clothing Store Landing Page
 Project Overview

Modern Threads is a responsive clothing store landing page developed as a mini project for Web Development Technologies (WDT).

The website is designed to provide a simple and attractive online shopping interface where users can explore clothing products across different categories such as Men, Women, Kids, and Sale.

 Features

- Clean and modern clothing-store interface
- Navigation bar with:
  - Men
  - Women
  - Kids
  - Sale
- Attractive hero section with a promotional message
- Featured Products section
- Product cards with:
  - Product images
  - Product names
  - Original prices
  - Discounted prices
- "Shop Now" button
- Login button
- Simple and user-friendly layout

Technologies Used

- HTML5
- CSS3
